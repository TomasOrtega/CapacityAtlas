Community workflow

GitHub Discussions holds research conversation. Issues track actionable corrections and repository work. Pull requests change the canonical database. This distinction keeps informal attempts visible without treating every idea as a mergeable claim.

Our contribution policy credits and adapts several practices from Formal Conjectures, especially statement-focused review, controlled metadata, shared pre-Mathlib infrastructure, and external links for long proofs.
