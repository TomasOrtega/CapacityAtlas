# Code of Conduct

Capacity Atlas is a technical collaboration. Participants must be respectful, precise, and constructive.

We welcome corrections and disagreement about mathematical claims. Critique the statement, proof, data, or code rather than the person. Do not harass, insult, threaten, discriminate against, or disclose private information about another participant. Avoid flooding discussions, misrepresenting sources, or repeatedly submitting claims after their evidentiary problems have been explained.

Maintainers may edit, hide, lock, or remove contributions that violate these expectations and may restrict participation when necessary. Report conduct concerns privately to the repository owner through the contact options on their GitHub profile. Maintainers should protect the reporter's privacy to the extent possible and explain enforcement decisions when doing so is safe.
